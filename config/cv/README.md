# config/cv/

Déposez ici votre CV au format PDF. Le skill `onboarding` le lit pour pré-remplir le questionnaire
(formations, expériences, compétences, langues). Rien n'est écrit dans votre profil sans votre
confirmation.

Ce dossier est ignoré par Git : votre CV reste sur votre machine. Pour le versionner malgré tout,
retirez la ligne `config/cv/*` du fichier `.gitignore`.
