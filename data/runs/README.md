# data/runs/

Un fichier par passage de collecte, nommé `AAAA-MM-JJ-HHMM.md`. Contenu : mode, heures de début
et de fin, requêtes et offres par source, statut de chaque source, erreurs détaillées. Format
défini dans la carte E6.3.

Les journaux de plus de 30 jours sont déplacés dans `archive/`, qui n'est pas versionné.
