# data/summaries/

Un fichier par jour, nommé `AAAA-MM-JJ.md`, mis à jour à chaque passage de la journée. Contenu :
nombre de nouvelles offres, offres au-dessus de votre seuil, top 10 par score, avertissements sur
les sources ou les mots-clés. Format défini dans la carte E6.3.

Pour le consulter : "montre-moi le résumé du jour".
